# План

Календар, розклад занять і конспекти в одному застосунку. Працює в браузері на Android, Windows і Linux, встановлюється як застосунок і відкривається без інтернету. Дані зберігаються у твоєму приватному репозиторії GitHub, тож сервер не потрібен.

## Як це влаштовано

- **Код** (цей репозиторій) — набір файлів HTML, CSS і JS. GitHub Pages роздає їх за адресою на кшталт `https://<логін>.github.io/<репозиторій>/`. Після першого відкриття Service Worker зберігає файли на пристрої.
- **Дані** живуть в окремому приватному репозиторії. Кожен запис — окремий Markdown-файл `entries/<uuid>.md` з короткою шапкою. Предмети лежать у `subjects/`, зображення — в `assets/`.
- **На пристрої** повна копія даних зберігається в IndexedDB. Будь-яка зміна спершу записується локально, а потім синхронізується.
- **Синхронізація.** Один запит перевіряє, чи змінився останній коміт. Якщо змінився, застосунок порівнює хеші файлів і завантажує тільки змінені. Свої зміни він відправляє одним комітом через Git Data API. Якщо той самий запис змінили на двох пристроях:
  - різні поля зливаються автоматично;
  - текст конспекту зливається по рядках, як у git;
  - якщо змінено одне й те саме, перемагає пізніша зміна, а інша версія потрапляє в журнал конфліктів з кнопкою «Відновити».
- **Простори.** Один простір = один репозиторій. Зазвичай їх два: особистий і спільний з другом. У календарі вони показуються разом різними кольорами.

## Налаштування з нуля (≈10 хвилин)

### 1. Опублікувати застосунок
1. Створи на GitHub **публічний** репозиторій, наприклад `plan`, і завантаж туди вміст цієї папки (`git push`). Публічний — бо GitHub Pages з приватного репозиторію на безкоштовному плані не працює. У коді немає жодних секретів.
2. Відкрий Settings → Pages → Build and deployment → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)` → Save.
3. Через хвилину застосунок буде доступний за адресою `https://<логін>.github.io/plan/`.

### 2. Особистий простір
1. Створи **приватний** репозиторій для даних, наприклад `plan-data`. Він може бути порожнім.
2. Створи токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Resource owner: ти.
   - Repository access: **Only select repositories** → `plan-data`.
   - Permissions → Repository permissions → **Contents: Read and write**.
3. У застосунку: Налаштування → «Мій простір» → «Підключити GitHub». Вкажи `логін/plan-data` і встав токен, потім натисни «Перевірити і зберегти».

### 3. Спільний простір з другом
Fine-grained токен не може писати в чужий особистий репозиторій, навіть якщо тебе туди запросили. Тому спільний репозиторій має належати **організації** (на GitHub вона безкоштовна).
1. GitHub → «+» → New organization → план Free. Назви, наприклад, `nerov-study` і запроси друга.
2. В організації: Settings → Personal access tokens → дозволь доступ через fine-grained tokens. Якщо ввімкнено схвалення запитів, власник схвалює токени тут же.
3. Створи в організації приватний репозиторій `shared`.
4. Кожен з вас створює собі токен: Resource owner = **організація**, репозиторій `shared`, Contents: Read and write.
5. У застосунку: Налаштування → «Додати простір» → тип «Спільний» → `nerov-study/shared` + токен.

Друг повторює кроки 2 і 3 зі своїм особистим репозиторієм і своїм токеном.

### 4. Телефон і інші пристрої
- На вже налаштованому пристрої: Налаштування → «Перенести налаштування на інший пристрій». Задай PIN і відскануй код камерою телефона. Токени передаються зашифрованими і лише в частині адреси після `#`, яку браузер нікуди не надсилає.
- **Android**: відкрий адресу в Chrome → меню → «Додати на головний екран» / «Встановити застосунок».
- **Windows**: Chrome або Edge → значок встановлення в адресному рядку.
- **Fedora KDE**: Chrome → значок встановлення в адресному рядку. Firefox поки не встановлює такі застосунки на Linux, але працює як звичайна вкладка.

### 5. Перенести події з Google Календаря
Google Календар → Налаштування → Імпорт і експорт → **Експортувати**. Вийде `.zip`. У застосунку: Налаштування → «Імпорт з Google Календаря» → обери цей файл. Для кожного календаря можна вказати простір і предмет. Повторний імпорт не створює дублікатів.

## Швидке додавання

Пиши одним рядком і тисни Enter. Що розпізнано, видно чипами під полем; помилковий чип вимикається кліком. `#назва` стає предметом, лише якщо такий предмет уже існує; інакше це звичайний тег.

| Приклад | Результат |
| --- | --- |
| `завтра 10:00-11:30 #матан лекція` | подія з часом і предметом |
| `щопн щср 8:30-9:50 #фізика пара` | повторюване заняття |
| `по пн, ср 10:00 англ` | повтор у кілька днів |
| `! здати лабу пт` | задача на п'ятницю |
| `20.11 ДН Олі`, `25 грудня`, `через 3 дні` | дати |
| `ідея для курсової #курсова` | нотатка без дати з тегом |

- Праворуч у рядку — кнопка для кожного простору, у його кольорі й з його значком. Натискання додає запис саме туди.
- **Enter** — в особистий простір або в простір предмета, якщо вказано `#предмет`. На комп'ютері цю кнопку видно за тонким кільцем.
- **Ctrl+Enter** — в інший простір.
- Налаштування → «Швидке додавання»: кнопка на кожен простір або одна кнопка з меню, підписи на кнопках, які простори показувати, колір і значок кожного простору.
- **Shift+Enter** — створити й одразу відкрити.

## Нотатки: папки і теги

- **Папки** — окремо від предметів, можуть бути вкладеними.
  - Створюються кнопкою «+» біля «Папки» на екрані нотаток.
  - Меню папки («⋯»): підпапка, перейменування, перенесення, видалення.
  - Видалення нічого не губить: нотатки й підпапки переходять на рівень вище.
  - Нотатку можна перетягнути на папку мишею або обрати папку у властивостях нотатки.
  - Нова нотатка створюється в папці, яка зараз відкрита.
- **Теги** — пиши `#слово` будь-де в назві чи тексті.
  - Після `#` з'являються підказки з наявних тегів.
  - Усі теги з лічильниками видно зліва на екрані нотаток, клік фільтрує.
  - Ctrl+клік по тегу в тексті показує всі нотатки з ним. Те саме робить пошук `#тег`.
  - `#3` і `# Заголовок` тегами не вважаються.
- **Вигляд списку:** картки або список, сортування за зміною, створенням чи назвою, швидкий фільтр.
- **Порожні нотатки** (без назви, тексту й дати) видаляються самі: при закритті, при переході деінде і при наступному запуску застосунку.

## Кольори подій

Колір події визначається так: свій колір події → колір предмета → колір простору. Свій колір вибирається в панелі події (чип «Колір»). У «Вигляді» → «Календар» → «Колір подій» можна поставити простір вище за предмет. Події зі спільних просторів мають значок простору перед назвою.

## Конспекти

- `#`, `##`, `###` — заголовки.
- `-` — список, `1.` — нумерований, `[]` — справа.
- `>` — цитата, `+` — розгортний блок, `!` — виноска.
- ``` ``` ``` — код, `$$` — формула блоком, `---` — розділювач.
- `**жирний**`, `*курсив*`, `~~закреслений~~`, `==виділення==`, `` `код` ``, `$x^2$` перетворюються одразу.
- `/` — меню всіх блоків. Є таблиці, зображення (вставляються з буфера) і посилання на інші нотатки `[[`.
- **Tab** / **Shift+Tab** — вкласти / винести.
- **Esc** — вибрати блок; потім ↑↓, Shift+↑↓, Del, Ctrl+D, Ctrl+C.
- **Ctrl+Shift+↑/↓** — перемістити блок. Блок можна й перетягнути за ручку ліворуч.
- **Ctrl+Z** / **Ctrl+Shift+Z** — скасувати / повторити.
- **Ctrl+B / I / E / K**, **Ctrl+Shift+S / H / M** — жирний, курсив, код, посилання, закреслений, виділення, формула.
- На телефоні над клавіатурою є панель з основними діями.

Формули пишуться у LaTeX (`\frac`, `\sqrt`, `\sum`, `\int`, `\lim`, матриці, `cases`, `\mathbb` тощо). Браузер малює їх сам через MathML, без зовнішніх бібліотек.

## Вигляд

Бічна панель → «Вигляд», або Ctrl+K → «вигляд». Будь-яка зміна одразу застосовується до всього застосунку.
- **Готові теми:** Стандарт, Мінімал, Північ, Теплий, OLED, Контраст. Тема — лише стартова точка, після неї можна змінити будь-яку деталь.
- **Кольори:**
  - світла, темна або як у системі;
  - тон фону (нейтральний, холодний, теплий), чиста чорна для OLED, висока контрастність;
  - 12 акцентів або будь-який свій колір. Якщо колір погано видно на фоні, застосунок трохи його підсвітить.
- **Розмір і форма:** масштаб 85–125 %, щільність, заокруглення, шрифт інтерфейсу і шрифт нотаток.
- **Календар:**
  - стиль подій: м'який, суцільний або контур;
  - висота години, також Ctrl + колесо в календарі;
  - вихідні, номери тижнів, початок тижня.
- **Робочий простір:**
  - стартовий екран;
  - рядок швидкого додавання: завжди видно або лише за клавішею N;
  - згорнута бічна панель (Ctrl+\);
  - які блоки показувати в панелі;
  - анімації.

## Гарячі клавіші

- `N` — швидке додавання, `Shift+N` — нова нотатка.
- `/` або `Ctrl+K` — пошук і команди.
- `T` — сьогодні.
- `D` / `W` / `M` — день / тиждень / місяць.
- `←` `→` — гортати календар.
- `Ctrl+\\` — згорнути бічну панель.
- `,` — налаштування, `Esc` — закрити.

## Обмеження

- Нагадування приходять, лише коли застосунок відкритий або згорнутий. Без сервера браузер не може розбудити закритий застосунок.
- Живої підписки на Google Календар немає: імпорт одноразовий. Зате є експорт у `.ics`.
- Конфлікт визначається за годинником пристроїв. Якщо годинник на пристрої сильно збитий, переможе не та версія. Втім, нічого не губиться: інша версія лишається в журналі конфліктів і в історії git.

## Розробка

Збирання не потрібне: це чисті ES-модулі.

```
python3 -m http.server 8123          # відкрити http://localhost:8123
node tests/unit-core.mjs              # дати, повтори, формат файлів
node tests/unit-md.mjs                # Markdown ⇄ блоки, формули
node tests/unit-io.mjs                # злиття, .ics, .zip, QR
node tests/e2e-sync.mjs               # два «пристрої» проти імітації GitHub (потрібен Playwright)
```

Структура: `js/store.js` (дані), `js/sync.js` + `js/github.js` + `js/merge.js` (синхронізація), `js/editor.js` + `js/md.js` + `js/math.js` (конспекти), `js/parse.js` (швидке додавання), `js/views/*` (екрани), `sw.js` (офлайн).

Після зміни будь-якого файлу підніми `VERSION` у `sw.js`, щоб пристрої отримали оновлення. Застосунок сам покаже «Доступна нова версія».
